EL PECIO OLVIDADO

«El fondo guarda un secreto. Solo quien sepa buscarlo podrá descubrirlo.»

Un pecio olvidado, tres objetos por encontrar y un secreto escondido en las profundidades.

Usa el ratón para orientar la linterna y la vista, W A S D para nadar.

Juega con el móvil en horizontal: joystick izquierdo para nadar, derecho para mirar. Para bajar, mira hacia abajo y nada hacia delante.

iPhone: gira el móvil y desliza hacia arriba para reducir la barra de Safari. Para pantalla completa real: Compartir → Añadir a pantalla de inicio y abre ABYSS desde el icono.

Tu navegador no admite gráficos 3D (WebGL): prueba con una versión reciente de Chrome, Safari, Firefox o Edge.
